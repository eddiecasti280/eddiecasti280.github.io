# Japanese Language and Travel Site
## Access
This site can be accessed via eddiecasti280.github.io.

## Introduction
This site is intended for new language learners in the Japanese language as well as people who would like to see how to navigate Japan for the first time. While not encompassing all different experiences, there is a substantial amount of information that would be able to help many learn the basics of the language and important notes on what is expected upon traveling for the first time.
